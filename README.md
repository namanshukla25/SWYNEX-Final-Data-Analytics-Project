# Cafe Sales Data Analytics Project

## Project Overview
This project analyzes cafe sales data to understand product performance, revenue patterns, customer transaction details, and data-quality issues. It was completed as part of my Data Analyst internship at SWYNEX Technologies.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI

## Project Workflow
1. **Data Cleaning:** Prepared the cafe sales dataset for analysis.
2. **Exploratory Data Analysis:** Used Python and Pandas to explore sales trends and identify patterns.
3. **Dashboard Development:** Created an interactive Power BI dashboard with KPI cards, charts, and filters.
4. **Reporting:** Summarized findings and business recommendations in a final report.

## Key Findings
- Coffee recorded 3,534 units sold in the analyzed data.
- Salad generated 17,320 in item-level revenue.
- 3,178 transactions had an unknown payment method.
- The analysis highlighted data-quality issues that should be considered before making business decisions.

*Note: These figures should be interpreted in the context of the available dataset and verified against the final notebook and dashboard.*
